# Examples

- [`helpdesk-api`](helpdesk-api/README.md) — a multi-module TypeScript HTTP API using Effect services, Layers, typed failures, immutable `Ref` state, and an executable service test.
- [`collaborative-docs`](collaborative-docs/README.md) — a Google Docs-inspired rich-text and Markdown editor with a revisioned realtime sync engine, concurrent edit rebasing, presence, and reconnect support.

The examples target the public modules bundled with Blitz and do not need an npm install or build step.
